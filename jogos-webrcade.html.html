Como usar e onde ficam os arquivos

Publique este HTML ao lado das pastas roms/ e capas/. Os nomes dos arquivos são os mesmos do catálogo anterior. Exemplo: roms/super-mario-world.sfc e capas/super-mario-world.png.

Cada cartão já abre uma partida diretamente. O feed é opcional: exporte-o aqui, hospede o JSON no seu site e adicione o endereço no webЯcade, ou importe o arquivo no editor.

A lista contém os 11 jogos cadastrados. Esta página não descobre arquivos novos automaticamente nas pastas. Ao adicionar jogos, acrescente novos cartões com os respectivos caminhos.

O estilo preto e verde vale para este catálogo. A aba de execução tem a interface, o ajuste de imagem e os controles próprios do webЯcade. A ponte de analógicos do EmulatorJS não é utilizada.

Os arquivos precisam estar acessíveis ao navegador e permitir acesso entre origens (CORS) pelo webЯcade. Não coloque senhas, tokens ou credenciais neste HTML ou no feed. Publique apenas conteúdo que você tem autorização para distribuir.

Validação desta entrega: inspeção estática. Ainda é necessário testar ROMs, capas, áudio, controle, teclado, saves e redimensionamento no site publicado.
